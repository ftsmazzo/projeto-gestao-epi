# ProntEPI · reel comercial (Instagram)

Video vertical **1080×1920**, ~24s, estilo SaaS para Reels/Stories/anúncios.

## Arquivo pronto

`out/prontepi-reel-instagram.mp4`

## Regenerar

```powershell
cd docs/manuais/ads
node record-prontepi-reel.mjs
```

Requisitos: Playwright em `docs/manuais/scripts` e FFmpeg no PATH.

## Cenas

1. Marca + headline
2. Painel do Cliente
3. Entrega facial + comprovante
4. Estoque + validade de CA
5. Mobile + Ficha de EPI
6. CTA InSeg / ProntEPI

Edite `prontepi-reel.html` para mudar textos, ordem ou prints.
