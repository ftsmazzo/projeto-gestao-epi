Fluxo recomendado (o mais fácil)

Melhor opção pra você: gravar tela muda + legenda grande no vídeo. O público lê o caminho enquanto você clica. Depois, se quiser voz, gera TTS em 5 minutos.
  1. OBS: só “Captura de tela”. Microfone desligado.
  2. Grave uma cena por vez (use o guia de gravação). Pause 1s quando a tela carregar.
  3. No CapCut: importe as cenas na ordem.
  4. Em cada cena, clique Copiar legenda abaixo e cole como texto na timeline (estilo legenda / título).
  5. (Opcional) Clique Copiar narração → ElevenLabs / CapCut Text-to-Speech / Edge Ler em voz alta → importe o áudio.
Importante: os tempos do SRT são estimados. No CapCut você arrasta o bloco até bater com o clique da tela. Não precisa bater no segundo.

Como gerar narração automática (opcional)

Se quiser voz sem gravar microfone:

  1. CapCut → Texto → Texto para fala (português BR) — cola a narração de cada cena.
  2. ElevenLabs (melhor voz): cole a narração, baixe MP3, coloque sob a cena.
  3. Microsoft Edge: abra esta página → botão direito → “Ler em voz alta” em um bloco colado no Bloco de Notas (rápido e grátis).
